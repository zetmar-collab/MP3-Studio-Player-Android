# MP3-Studio Player na Androida

Odtwarzacz muzyki, radia internetowego i podcastów na Androida 8.0 lub nowszego.

## Pobieranie

Plik APK znajdziesz w sekcji [Releases](https://github.com/zetmar-collab/MP3-Studio-Player-Android/releases/latest).

Telefon poprosi o zgodę na instalację z nieznanego źródła, bo aplikacja nie pochodzi ze sklepu.

Suma SHA-256 wersji 1.0:

```
d8c9f809e25a6ada4a1440bbab2d6cb6f15c1f29868cb6d807b4091c23c3fc07
```

## Co potrafi

- Odtwarza muzykę z telefonu, także w tle, z obsługą z powiadomienia
- Playlisty: tworzenie oraz import i eksport plików M3U, PLS i XSPF
- Radio internetowe: wyszukiwanie według nazwy, kraju i gatunku oraz ulubione stacje
- Podcasty: wyszukiwanie, dodawanie po adresie i oznaczanie odsłuchanych odcinków
- Korektor dźwięku, jeśli urządzenie go udostępnia
- Motyw jasny, ciemny lub systemowy, język polski i angielski

## Stan wersji 1.0

To pierwsza wersja. Testowana na emulatorze z Androidem 37, jeszcze nie na fizycznym telefonie.

- Nie ma jeszcze Last.fm, kategorii podcastów ani importu i eksportu OPML.
- Część stacji radiowych odmawia połączenia. Aplikacja pokazuje wtedy komunikat.

## Prywatność

Aplikacja nie ma konta ani reklam. Internetu używa tylko do radia i podcastów: łączy się z usługami wyszukiwania oraz z serwerami wybranych stacji i podcastów, które widzą przy tym adres IP urządzenia. Część stacji nadaje przez nieszyfrowane połączenie http.

Kod źródłowy nie jest publikowany w tym repozytorium. Wszelkie prawa zastrzeżone.
